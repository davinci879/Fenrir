# Fenrir 专利写作助手

基于 PyQt5 的专利申请文件撰写辅助工具，集成多 Tab 编辑、附图标记管理、结构导航、文本校验、OCR 识别等功能。

## 运行环境

- Python 3.8+
- Windows（依赖 win32api/win32gui）
- 依赖：PyQt5, qtawesome, requests, opencv-python, numpy, pywin32

安装依赖：

```
pip install PyQt5 qtawesome requests opencv-python numpy pywin32
```

启动：

```
python main.py
```

## 功能模块

### 主编辑区（main.py）

- **多 Tab 文本编辑器**：每个 Tab 对应一份申请文件段落，支持新建、关闭、拖拽排序
- **结构导航**：左侧树状面板，按"技术领域 / 背景技术 / 发明内容 / 附图说明 / 具体实施方式 / 权利要求书 / 摘要"导航，点击跳转
- **权利要求层级视图**：自动识别独权/从权，按引用关系缩进展示，鼠标悬停显示特征部分全文
- **查找替换**：Ctrl+F 唤起，支持查找上一个/下一个、单处替换、全部替换
- **附图标记补全**：从说明书正文中提取"名称(标号)"格式的附图标记，自动补全到对应位置
- **文本校验**：
  - 术语一致性：标号相同名称不同、名称相同标号不同，高亮并列入表格
  - 专利法 26 条 3/4 款自检：统计"等""大约""优选地"等空泛词
- **自动摘要生成**：提取独立权利要求 + 主要技术特征，生成 300 字以内摘要草稿，插入光标处
- **右键菜单**：专利检索（CNIPA/Espacenet）、自动摘要生成
- **复制为纯文本**：QTextCursor 的 `\u2029` 段落符自动转 `\r\n`，可粘贴到 Notepad

### 附图编辑器（txteditor_figeditor.py）

- **四种标注模式**：线条标注、曲线标注（美国专利风格 S 形贝塞尔引出线）、文字标注、阅览模式
- **曲线标注**：两段贝塞尔组成平滑 S 形，连接点按 3:2 比例，数字位于弧线外端不与曲线干涉
- **百度 OCR**：识别附图中的文字
- **图像处理**：转线条图、图像锐化
- **支持拖拽图片入画布**、保存标注结果

### 图像调整（txteditor_adjustimg.py）

- numpy 向量化找边界，快速裁剪/摆正附图

### 资源工具（resource.py）

- 预编译正则，附图标记提取、术语一致性校验、空泛词统计等公共函数
