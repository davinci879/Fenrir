常见错误的解决方案：
Q1：CMD窗口弹出后一闪即消失，且之后再无响应？
A1：请确认已经解压缩了全部文件，如果只提取exe文件，或改变文件夹构成，程序将无法运行。
Q2：能够弹出登录窗口，点击登录、注册均无响应？
A2：请确认能够正常访问http://www.fenrir.fun/port，如果无法访问请尝试修改DNS为其他，eg：8.8.8.8。
Q3：可以弹出注册窗口，且信息填写无误，但点击注册账号后无响应？
A3：请确认当前程序为最新版本。
Q4：主窗口积分显示为：N/A
A4：网络不畅导致，再次使用消耗积分的模块即可恢复正常。
Q5：之前使用正常，当前却无法登录，提示“提示服务器正在维护”？
A5：请直接联系管理员。
Q6：点击按钮无响应，或“提示服务器正在维护”。
A6：重启程序，如过仍然无法使用，请联系管理员。
Q7：点击按钮后，所有按钮变为灰色，且无法再次操作。
A7：关闭当前模块，重新载入（无需关闭全部程序）。
Q8：其他无法启动，或可以启动无法连接服务器的问题。
A8：WIN10以上用户，请确认已经获取了管理员权限。请检查防火墙和杀毒软件是否已将本软件端口屏蔽，导致无法与服务器正常通讯。
